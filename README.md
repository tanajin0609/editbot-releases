# AutoEditBot releases

AutoEditBot のインストーラーと本体を配布するためのリポジトリです。ソースコードはここにはありません。

## インストール

1. [Releases](https://github.com/tanajin0609/editbot-releases/releases/latest) から `AutoEditBotSetup.exe` をダウンロードして実行します。
2. インストーラーが、同じ Release に置いてある本体（`AutoEditBot-v<版>.zip`）をダウンロードして展開します。インストール中はネットにつながっている必要があります。

- 対応: Windows 11（64 ビット）
- インストール先: `%LOCALAPPDATA%\Programs\AutoEditBot`（管理者権限は不要です）
- 本体の zip は、各 Release に書いてある SHA-256 で破損していないか確かめてから展開します。
